# 모두의 드럼 연습기 (1단계)

메트로놈 + 듣는 장치별 지연 보정 + 실시간 박자 판정 웹앱임.

## 파일
- `index.html` : 앱 본체 (이 파일 하나로 동작함)
- `manifest.webmanifest`, `sw.js`, `icon.svg` : 폰 홈 화면에 앱처럼 설치하기 위한 파일

## 실행 방법
- PC 크롬: `index.html`을 크롬으로 열면 바로 실행됨 (마이크 권한 허용 필요)
- 스마트폰: 마이크는 https 주소에서만 켜지므로 인터넷 주소로 올려야 함
  - 추천: GitHub Pages에 `app` 폴더를 올림 → 폰 크롬으로 접속 → 메뉴 → '홈 화면에 추가'

## 처음 쓸 때 순서
1. 설정 탭 → 마이크 켜기 → '조용히 2초 두고 자동 설정' → 몇 번 쳐서 막대가 빨간 선을 넘는지 확인
2. 보정 탭 → 듣는 장치 선택 또는 추가 → 보정 시작
   - 폰 스피커: '자동 측정' → 치지 않고 가만히 둠 → 클릭이 마이크에 들어오는 시간·크기를 재서, 연습 중 클릭 소리를 타격으로 세지 않음
   - 이어폰·블루투스: 클릭 16번에 맞춰 치기
   - 앱은 지금 어떤 장치로 소리가 나가는지 스스로 알 수 없음(브라우저 제한) → 연습 화면에서 직접 고름
3. 연습 탭 → 듣는 장치 선택 → BPM, '내가 치는 가장 잘게 쪼갠 음표' 고르기 → 시작

## 판정 방식
- 마이크 소리가 갑자기 커지는 첫 순간을 '친 시각'으로 잡음 (오디오 시계 기준, 1ms 이하 정밀도)
- 친 시각 − 장치 보정값 → 가장 가까운 격자(4분/8분/셋잇단/16분)와의 차이를 ms로 표시
- 판정 기준(설정 탭): 여유 ±25/50ms, 보통 ±15/35ms, 엄격 ±8/20ms
- 어떤 북·심벌을 쳤는지는 아직 구분하지 않음 (3단계 예정)

## 연습 기능
- 메트로놈 끊기 연습: 일부 마디를 무음으로 만들고, 무음 마디에서 템포가 밀리는지 결과에 따로 표시함
- 격자마다 다 치는 연습: 패드 싱글 스트로크 연습용. 빠뜨린 박을 '놓침'으로 표시함
- 연습 종료 시 결과 요약(정확도, 평균 오차, 흔들림, 뒤로 갈수록 밀림/당김) → 기록 탭에 저장

## 검증 결과 (개발 중 테스트)
- 알고 있는 간격의 합성 타격음을 가상 마이크로 넣었을 때 타격 간격 오차 0.2ms 이내
- 보정 → 판정 계산을 거친 오차가 넣은 값과 1ms 이내로 일치함
- 실제 폰 마이크·이어폰 환경 테스트는 아직 안 함
